## Overview

TAL-J-8 accurately models the Roland Juno-106 with DCO oscillators, the iconic HPF/LPF filter, chorus unit simulation, and full MIDI CC mapping for authentic 80s analog pad and bass sounds.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TAL-J-8** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **DCO Model** | Discrete-component DCO simulation with sawtooth, pulse, and sub |
| **Juno Filter** | Analog-modeled 24dB Juno HPF and LPF filter with transistor character |
| **Chorus Unit** | Two-mode chorus unit matching the Juno-106 MN3009 bucket brigade |
| **MIDI CC Map** | Full MIDI CC compatibility with original Juno-106 controller data |
